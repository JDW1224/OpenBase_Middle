# 콘솔 비밀번호 생성기

C로 작성한 비밀번호 생성·문자 구성 검사·텍스트 저장 학습 프로젝트다. 사이트와 아이디, 원하는 길이를 입력받아 대문자·소문자·숫자·특수문자를 포함하는 문자열 생성을 시도한다.

## 기능과 구성

| 파일 | 역할 |
| --- | --- |
| `main.c` | 기능 선택과 반복 실행 |
| `basement.h` | 메뉴·구분선·종료 확인 등 콘솔 인터페이스 |
| `password_create.h` | 문자열 생성, 문자 구성 검사, 파일 저장 |
| `Id_Password.txt` | 실행 시 생성되는 사이트·아이디·암호 출력 파일 |

생성기는 `rand()`로 문자를 고르고 `Check()`에서 문자 종류를 검사한다. 결과는 현재 작업 폴더의 `Id_Password.txt`에 추가된다.

## 개발 환경

`conio.h`, `_getch()`와 MSVC 경고 설정을 사용하는 Windows 콘솔 코드다. 별도 솔루션이나 빌드 스크립트는 포함되어 있지 않다.

Visual Studio의 C/C++ 콘솔 프로젝트에 `main.c`와 두 헤더를 추가해 확인할 수 있다. 현재 소스는 시간 함수 헤더·함수 선언과 반환, 문자열 종료 및 입력 처리 정비가 필요하므로 그대로 빌드·실행된다고 검증한 상태는 아니다.

## 구현 상태

- 문자열 생성·문자 구성 검사·평문 파일 저장을 구현한 프로토타입이다.
- 입력 길이 검증과 메모리·문자열 처리를 보완해야 한다.
- 메뉴의 문자 종료 입력 처리도 정비가 필요하다.
- 암호학적 난수나 암호화 저장을 구현하지 않았다. 생성 결과 파일에는 실제 계정 정보를 넣지 않으며 Git 추적에서 제외한다.

이번 문서 정리에서는 프로그램을 실행하지 않았다.
